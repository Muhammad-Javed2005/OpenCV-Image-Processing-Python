##  Overview

This repository is a **complete hands-on learning journey for OpenCV and
Computer Vision**.\
It is structured into multiple **phases**, starting from basic image
processing to **advanced deep learning-based computer vision systems**.

The goal of this repository is to help learners and developers
understand:

-   Image Processing
-   Computer Vision Techniques
-   Object Detection
-   Feature Engineering
-   Face Recognition
-   Video Analytics
-   OCR and Document Vision

Each phase builds upon the previous one, making this repository a
**step-by-step roadmap to mastering OpenCV**.

#  Learning Roadmap

This repository follows a **progressive learning path**.

## Phase 0 -- Getting Ready for OpenCV

Setup and preparation for working with OpenCV and image processing.

------------------------------------------------------------------------

## Phase 1 -- Getting Started With OpenCV

Basic operations including:

-   Loading images
-   Displaying images
-   Image dimensions
-   Converting images to grayscale
-   Saving images

------------------------------------------------------------------------

## Phase 2 -- Image Transformation & Manipulation

Learn how to manipulate images using:

-   Cropping
-   Resizing
-   Rotation
-   Flipping
-   Drawing shapes (circle, rectangle, line)
-   Adding text

------------------------------------------------------------------------

## Phase 3 -- Video & Webcam Processing

Working with real-time video streams:

-   Capturing webcam video
-   Saving video output
-   Frame processing

------------------------------------------------------------------------

## Phase 4 -- Image Filtering & Blurring

Noise reduction and smoothing techniques:

-   Gaussian Blur
-   Median Blur
-   Image Sharpening

------------------------------------------------------------------------

## Phase 5 -- Edge Detection & Thresholding

Important computer vision techniques:

-   Canny Edge Detection
-   Thresholding
-   Bitwise operations

------------------------------------------------------------------------

## Phase 6 -- Contours & Shape Detection

Detect and analyze object shapes using:

-   Contour detection
-   Shape analysis

------------------------------------------------------------------------

## Phase 7 -- Face & Object Detection

Using Haar Cascade models for:

-   Face detection
-   Eye detection
-   Smile detection

------------------------------------------------------------------------

## Phase 8 -- Feature Engineering

Key feature extraction techniques:

-   SIFT Features
-   ORB Features
-   Harris Corner Detection
-   Shi-Tomasi Corner Detection
-   Feature Matching
-   Homography

------------------------------------------------------------------------

## Phase 9 -- Image Segmentation

Segment images using:

-   K-Means Segmentation
-   Watershed Algorithm
-   GrabCut

------------------------------------------------------------------------

## Phase 10 -- Traditional Object Detection

Classical computer vision approaches:

-   HOG Person Detection
-   Template Matching
-   Selective Search

------------------------------------------------------------------------

## Phase 11 -- Deep Learning with OpenCV

Deep learning models for computer vision:

-   MobileNet SSD
-   YOLO Object Detection
-   DNN Image Classification
-   DNN Face Detection

------------------------------------------------------------------------

## Phase 12 -- Face Recognition & Tracking

Advanced applications:

-   Face recognition system
-   Face embeddings
-   Object tracking (CSRT, KCF)
-   Attendance system using face recognition

------------------------------------------------------------------------

## Phase 13 -- Video Analytics

Real-world video analysis systems:

-   Motion Detection
-   Background Subtraction
-   People Counter
-   Speed Estimation

------------------------------------------------------------------------

## Phase 14 -- OCR & Document Vision

Extract text and information from images:

-   Document Scanner
-   ID Card Information Extractor
-   OCR using Tesseract

------------------------------------------------------------------------

### 2️⃣ Navigate to Project Folder

    cd OpenCV-Image-Processing-Python

    pip install opencv-python numpy

Example:

    python draw_circle.py
